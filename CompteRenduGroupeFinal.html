Partie 1: Rapport initial

1. Présentation du problème

Le problème étudié est le problème de coloration de graphes.
L’objectif est de définir des règles logiques permettant, à partir d’un graphe donné et d’un nombre de couleurs donné, d'utiliser un SAT-Solver pour vérifier si une coloration valide du graphe est possible et, le cas échéant, en déterminer une.

Un graphe colorable est un graphe où l’on peut attribuer des couleurs aux sommets sans que deux sommets adjacents aient la même couleur.

3. Particularité des indices

Dans un SAT-Solver, chaque variable xi,jx_{i,j}xi,j​ doit être représentée par un nombre entier unique.
On utilise la transformation suivante :

Var(i,j)=(i−1)×k+j\text{Var}(i, j) = (i - 1) \times k + jVar(i,j)=(i−1)×k+j

où :

  • iii est le sommet (1≤i≤n1 \leq i \leq n1≤i≤n)
  • jjj est la couleur (1≤j≤k1 \leq j \leq k1≤j≤k)
  • kkk est le nombre total de couleurs

Exemple : Si nous avons 4 sommets et 3 couleurs, on numérote ainsi :

Sommet iii Couleur 1 Couleur 2 Couleur 3
1 1 2 3
2 4 5 6
3 7 8 9
4 10 11 12

Ainsi :

  • x1,1=1x_{1,1} = 1x1,1​=1 → "Sommet 1 est coloré en couleur 1"
  • x2,3=6x_{2,3} = 6x2,3​=6 → "Sommet 2 est coloré en couleur 3"

4. Exemples concrets de colorations de graphes

Pour mieux comprendre les contraintes et les résultats obtenus avec un SAT-Solver, voici plusieurs cas particuliers qui illustrent différentes situations de coloration de graphes.

Cas 1 : Graphe sans arêtes (graphe vide)

Description
Un graphe sans arêtes est un ensemble de sommets isolés, c'est-à-dire qu'aucun sommet n’est connecté à un autre.

Résultat attendu
Dans ce cas, toutes les colorations sont valides puisque aucune contrainte ne lie les sommets.
Chaque sommet peut prendre n’importe quelle couleur indépendamment des autres.

Exemple

  • Graphe avec 4 sommets et 3 couleurs disponibles
  • Possible colorations :
    • (1: Rouge, 2: Bleu, 3: Vert, 4: Rouge)
    • (1: Bleu, 2: Bleu, 3: Bleu, 4: Bleu)

Cas 2 : Un seul sommet avec plusieurs couleurs disponibles

Description
Si un graphe ne contient qu'un unique sommet, alors ce sommet peut être colorié librement, quelle que soit la quantité de couleurs disponibles.

Résultat attendu
Le problème est toujours SATISFIABLE, car il n'y a aucune restriction sur la couleur choisie.

Exemple

  • Graphe avec 1 sommet et 3 couleurs disponibles
  • Possible solutions :
    • (1: Rouge)
    • (1: Bleu)
    • (1: Vert)

Cas 3 : Nombre de couleurs insuffisant

Description
Si un graphe contient une structure nécessitant au moins kkk couleurs, mais qu’on impose seulement k−1k-1k−1 couleurs, alors la solution devient impossible.

Résultat attendu
Le SAT-Solver renverra "UNSAT" car aucune coloration valide ne respecte les contraintes.

Exemple : Cycle impair et 2 couleurs

  • Un cycle de longueur impaire (ex: triangle) nécessite au moins 3 couleurs.
  • Si on impose seulement 2 couleurs, la contrainte "deux voisins doivent être différents" ne peut pas être satisfaite.
  • Résultat : UNSAT

Cas 4 : Plus de couleurs que de sommets (∣C∣>∣X∣|C| > |X|∣C∣>∣X∣)

Description
Si le nombre de couleurs disponibles est strictement supérieur au nombre de sommets, alors il existe toujours au moins une solution.

Résultat attendu
Le problème est SATISFIABLE et le SAT-Solver renverra une solution.

Exemple

  • Graphe avec 3 sommets et 5 couleurs
  • Possible solutions :
    • (1: Rouge, 2: Bleu, 3: Vert)
    • (1: Bleu, 2: Vert, 3: Jaune)

Observation

  • Ajouter des couleurs ne peut jamais rendre un problème UNSAT, mais il augmente les possibilités de solutions.

Cas 5 : Graphe nécessitant exactement kkk couleurs

Description
Certains graphes nécessitent exactement kkk couleurs et ne peuvent pas être coloriés avec moins.

Résultat attendu
Si on donne moins de couleurs que nécessaire, on obtient UNSAT.
Si on donne exactement kkk couleurs, le SAT-Solver trouve une solution unique.

Exemple : Cycle de longueur paire avec 2 couleurs

  • Un cycle de longueur paire (ex: carré, hexagone...) peut toujours être colorié avec 2 couleurs.
  • Résultat attendu : SAT
  • Coloration typique :
    • (1: Rouge, 2: Bleu, 3: Rouge, 4: Bleu)

Observation

  • Ce cas est limite entre "SAT" et "UNSAT" : avec 2 couleurs, c’est possible, avec 1 couleur, c’est impossible.

Partie 2 : Rapport final

Explication détaillée de l'algorithme

Voici les étapes détaillées du processus :

  1. Entrées :

    • Le programme prend en entrée un graphe sous forme de sommets et d'arêtes ainsi qu'un nombre défini de couleurs à utiliser pour la coloration.

  2. Transformation du graphe :

    • Le graphe est analysé, et chaque sommet est transformé en variables logiques qui représentent les couleurs possibles pour ce sommet.

  3. Application des contraintes (règles) :

    • Des contraintes spécifiques sont définies pour garantir que :
      • Chaque sommet possède exactement une couleur.
      • Deux sommets voisins ne partagent jamais la même couleur.

  4. Génération du fichier DIMACS :

    • L'ensemble des contraintes est traduit en clauses logiques et formaté dans un fichier DIMACS standard, compatible avec le solveur SAT MiniSAT.

  5. Résolution avec MiniSAT :

    • Le fichier DIMACS est soumis au solveur MiniSAT qui détermine la satisfaisabilité des contraintes et fournit une solution sous forme d'affectation des variables.

  6. Interprétation des résultats :

    • La solution obtenue du solveur est traduite de l'espace logique vers la coloration concrète du graphe initial, associant clairement chaque sommet à sa couleur correspondante.

  7. Vérification de la solution :

    • Une étape de validation vérifie minutieusement que :
      • Chaque sommet dispose d'exactement une couleur.
      • Aucun sommet voisin ne partage la même couleur, respectant ainsi les contraintes initiales du problème.

  8. Affichage des résultats :

    • Finalement, si la coloration est possible, le graphe coloré est affiché dans une interface graphique et les affectations de ses couleurs sont affichées dans le terminal, sinon le terminal affiche INSATISFIABLE.

Explication de l'exécution et des formats

Prérequis

Pour utiliser correctement le programme, assurez-vous que les outils suivants sont installés sur votre machine :

  • Python 3

    sudo apt-get install python3

  • Solveur MiniSAT

    sudo apt-get install minisat

Représentation des sommets et des couleurs

  • Les sommets et les couleurs sont représentés exclusivement par des entiers positifs ou nuls.
  • Les couleurs commencent à l'entier 0 et augmentent progressivement (0, 1, 2, ...).

Format du fichier d'entrée (graphe)

Le fichier texte représentant le graphe doit suivre exactement ce format :

sommet: [voisin1, voisin2, voisin3, ...]
  • Chaque sommet est identifié par un entier.
  • Les sommets doivent être numérotés consécutivement de 1 à N, où N est le nombre total de sommets.
  • Un sommet sans voisins ne sera pas représenté dans le fichier.

Exemple de fichier graphe :

1: [2, 3]
2: [1, 4, 5]
3: [1, 6]
4: [2, 5, 7]
5: [2, 4, 6, 8]
6: [3, 5, 9]
7: [4, 8]
8: [5, 7, 9]
9: [6, 8]

Exemple d'exécution du programme

Pour lancer le programme, utilisez la commande suivante dans le terminal :

python3 colorier_graphe.py graphe.txt 3

Cette commande lance la coloration du graphe contenu dans le fichier graphe.txt avec 3 couleurs disponibles.
